# წარმოებაში გაშვების წინა ჩექლისტი (Pre-Launch Checklist)

სისტემის რეალურ მომხმარებლებთან გაშვებამდე გაიარეთ ეს ჩექლისტი, რათა დარწმუნდეთ, რომ ყველა პარამეტრი და უსაფრთხოების მექანიზმი გამართულია.

---

## 1. გარემოს ცვლადები (`.env.local`)
- [ ] `ADMIN_PASSWORD` შეცვლილია რთულ, უსაფრთხო პაროლზე.
- [ ] `SESSION_SECRET` შეცვლილია უნიკალურ, შემთხვევით 32+ სიმბოლოიან სტრიქონზე.
- [ ] `LLM_PROVIDER` არჩეულია (`gemini`, `openai` ან `anthropic`).
- [ ] შესაბამისი პროვაიდერის გასაღები შევსებულია (`GEMINI_API_KEY`, `OPENAI_API_KEY` ან `ANTHROPIC_API_KEY`).
- [ ] `NEXT_PUBLIC_SUPABASE_URL` და `SUPABASE_SERVICE_ROLE_KEY` შევსებულია რეალური Supabase პროექტით.

---

## 2. ბიზნესის მონაცემები & პრომპტი
- [ ] `supabase/seed.sql`-ში ან ადმინ პანელის **პარამეტრებში** (`/admin` -> პარამეტრები) შევსებულია:
  - [ ] ბრენდის ოფიციალური სახელი (`brand_name`)
  - [ ] სამუშაო საათები (`working_hours`)
  - [ ] მხარდაჭერის საკონტაქტო ტელეფონი (`support_phone`)
  - [ ] მიტანის ტარიფები (`delivery_fee_city`, `free_delivery_threshold`)
  - [ ] TBC და საქართველოს ბანკის რეალური ანგარიშის ნომრები (IBAN)
  - [ ] შპს-ს / ინდმეწარმის ოფიციალური დასახელება და საიდენტიფიკაციო კოდი
- [ ] კატალოგში შეტანილია რეალური პროდუქტები, აქტუალური ფასები და ნაშთები (ხელით ან CSV იმპორტით).

---

## 3. არხების კონფიგურაცია
- [ ] **Telegram:**
  - [ ] `TELEGRAM_BOT_TOKEN` შემოწმებულია.
  - [ ] Webhook დაყენებულია HTTPS მისამართზე (`/api/webhooks/telegram`).
  - [ ] Telegram-ზე გაგზავნილია სატესტო შეტყობინება და მიღებულია პასუხი.
- [ ] **WhatsApp Cloud API:**
  - [ ] Phone Number ID და Permanent Access Token ვალიდურია.
  - [ ] Webhook ვერიფიკაცია წარმატებით გაიარა Meta Developer პორტალზე.
  - [ ] Subscribed Fields-ში ჩართულია `messages`.
- [ ] **Facebook Messenger:**
  - [ ] Page Access Token და App Secret შემოწმებულია.
  - [ ] Webhook გამოწერილია დაკავშირებული Facebook გვერდისთვის (`messages`, `messaging_postbacks`).

---

## 4. ფინანსური & ოპერაციული ტესტი
- [ ] გაფორმდა სატესტო შეკვეთა ქართული მობილურის ნომრითა და თბილისის მისამართით.
- [ ] შემოწმდა, რომ შეკვეთა აისახა ადმინ პანელში სტატუსით `AWAITING_PAYMENT`.
- [ ] გაიგზავნა სატესტო ქვითარი:
  - [ ] AI-მ არ დაადასტურა გადახდა დამოუკიდებლად.
  - [ ] ჩანაწერი გამოჩნდა ადმინ პანელში განყოფილებაში "გადახდები" (`PAYMENT_REVIEW`).
  - [ ] ადმინმა დააჭირა "დადასტურებას", სტატუსი გადავიდა `CONFIRMED_PAID`-ზე.
- [ ] შემოწმდა ოპერატორის ჩართვის რეჟიმი:
  - [ ] ჩათში გაიგზავნა "ოპერატორთან დაკავშირება".
  - [ ] AI გაჩერდა (`aiPaused: true`).
  - [ ] ადმინმა ინბოქსიდან გააგზავნა პირდაპირი პასუხი მომხმარებელთან.

---

## 5. Cron & Outbox
- [ ] დაყენებულია Cron Job (მაგ: Vercel Cron ან cron სერვისი), რომელიც პერიოდულად (ყოველ 1-2 წუთში) იძახებს `/api/cron/outbox` `CRON_SECRET` ჰედერით, რათა მოხდეს დაყოვნებული შეტყობინებების გაგზავნა.
