# დოკუმენტაცია — OmniFlow AI Agent (Georgian Edition)

ეს დირექტორია შეიცავს სრულ ტექნიკურ და საოპერაციო დოკუმენტაციას ომნიჩენელ AI გაყიდვებისა და მომხმარებელთა მხარდაჭერის აგენტისთვის (ვერსია 1.0 — ქართული).

## დოკუმენტების სარჩევი

1. **[არქიტექტურა (ARCHITECTURE.md)](./ARCHITECTURE.md)**
   - სისტემის კომპონენტები, ტექნოლოგიური სტეკი (Next.js 16 + React 19 + Supabase).
   - მონაცემთა ბაზის რეპოზიტორიის აბსტრაქცია (Supabase vs In-Memory რეჟიმი).
   - აგენტის ორკესტრაცია, Tool Calling ციკლი და Transactional Outbox მოდელი.

2. **[Supabase-ის გამართვა (SETUP_SUPABASE.md)](./SETUP_SUPABASE.md)**
   - პროექტის შექმნა Supabase-ში.
   - მიგრაციის გაშვება (`supabase/migrations/0001_init.sql`) — 15 ცხრილი, RPC ფუნქციები, RLS.
   - საწყისი მონაცემების შეტანა (`supabase/seed.sql`) — ბიზნეს კონფიგი და სატესტო პროდუქცია.
   - გასაღებების მიღება და `.env.local`-ში ჩაწერა.

3. **[არხების ინტეგრაცია (SETUP_CHANNELS.md)](./SETUP_CHANNELS.md)**
   - **Telegram:** BotFather-ით ბოტის შექმნა, Webhook vs ლოკალური Long Polling რეჟიმი.
   - **WhatsApp Business Cloud API:** Meta Developers პორტალი, მუდმივი ტოკენი, Webhook Handshake და HMAC ვერიფიკაცია.
   - **Facebook Messenger:** Meta App, გვერდის დაკავშირება, Page Access Token და ხელმოწერის შემოწმება.

4. **[უსაფრთხოება & დაცვა (SECURITY.md)](./SECURITY.md)**
   - Prompt Injection-ისგან დაცვა და ინსტრუქციების იზოლაცია.
   - ფინანსური უსაფრთხოება: რატომ არ ადასტურებს AI გადახდას ავტომატურად (მხოლოდ `PAYMENT_REVIEW` და ადამიანის კონტროლი).
   - ვებჰუკების HMAC-SHA256 ციფრული ხელმოწერების შემოწმება.
   - ადმინ პანელის სესიის დაცვა და PII (პერსონალური მონაცემების) დაბინდვის მექანიზმი.

5. **[ტესტირება (TESTING.md)](./TESTING.md)**
   - ავტომატური ტესტების გაშვება (`npm test`).
   - 12 კრიტიკული ბიზნეს-სცენარის მიმოხილვა (`tests/scenarios.test.ts`).
   - ლოკალური ტესტირება ინტერნეტის/ვებჰუკების გარეშე (`npm run telegram:poll`).

6. **[გაშვების წინა ჩექლისტი (LAUNCH_CHECKLIST.md)](./LAUNCH_CHECKLIST.md)**
   - ცვლადების გადამოწმება გაშვებამდე (`{{...}}` ჩანაცვლება).
   - ბანკის რეკვიზიტების და საკურიერო ტარიფების ვალიდაცია.
   - სატესტო შეკვეთის სრული ციკლი წარმოებაში გაშვებამდე.
